# Numberduel

A two-player, turn-based card game where you build math expression "chains"
across three elements — Sun, Snow, and Sky — racing to complete computable
chains before your opponent while a shot clock counts down each turn.

## Play it

The game will be live at:

```
https://<your-username>.github.io/numberduel/
```

## Running it locally

No installation needed — it's a single self-contained HTML file.
Just download `index.html` and open it in any web browser.

## How to play

Full rules are built into the game itself — click **"How to Play"** on the
setup screen before starting a duel.
